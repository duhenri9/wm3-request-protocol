# Glossário

## Linha de controle

A coerência entre intenção, promessa pública, implementação e próximos passos.

## Fonte de verdade

O artefato usado como referência para decidir o que deve ser preservado.

Pode ser uma URL, commit, PR, documento, print, copy aprovada ou regra de negócio.

## Gate

Condição que precisa ser cumprida antes de avançar.

Exemplo: só divulgar uma página depois que o formulário entrega e-mail real.

## Falso positivo

Quando o sistema indica sucesso, mas a operação real falhou.

Exemplo: formulário retorna "pedido recebido" sem e-mail entregue, webhook salvo ou banco persistido.

## Fora do escopo

Tudo que não deve ser alterado nesta mudança.

## Critério de pronto

Conjunto de condições observáveis para considerar a tarefa concluída.

## Requisição

Pedido estruturado de mudança.

## PR

Pull Request: proposta de alteração no código.
